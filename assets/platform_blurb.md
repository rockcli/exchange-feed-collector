Reference implementation · live public exchange sample + deterministic offline replay

Built a resilient multi-exchange market data collector in Python (`asyncio` + `aiohttp` + SQLite WAL) normalizing live WebSocket and REST feeds from Coinbase (`BTC-USD`), Kraken (`XBT/USD` → `BTC-USD`), and OKX (`BTC-USDT`) while keeping quote currencies explicit. The pipeline pairs capped jittered exponential backoff, a per-venue circuit breaker verified only on persisted market ticks, monotonic stale-feed detection wired into active WS reconnect + REST fallback, and non-blocking REST gap backfill with strict window/new-row verification and `INSERT OR IGNORE` deduplication (`UNIQUE(run_id, exchange, symbol, ts_ms, source, dedup_seq)`). Verified with both deterministic offline replay (`177` deduplicated ticks from `179` raw inputs, `1` recovered 7s gap, `22` passing tests under strict `ruff` and `mypy`) and a live 45-second multi-venue capture (`1,543` stored ticks from `1,614` raw frames, `0.83 bps` abs / `+0.75 bps` signed mean `USD-USD` spread, `15.88 bps` mean `USDT-USD` basis, `159.0–241.0 ms` live `p95` non-skewed ingest latency), emitting HTML, PNG, and structured JSON reports.

Built with AI-assisted tooling; architecture, review, and tests by me.
